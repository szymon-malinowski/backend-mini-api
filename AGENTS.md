# Mini Project

## Description

In this mini project, you are required to implement an API with **at least 2 endpoints** and the following specifications:

- Related Entities: It should have at least two related entities (e.g., User and Post, Product and Category, etc.).
- Security: The API should be able to handle most or all the security concerns discussed in the course.
- Database: The API must use PostgreSQL as its only database to store and retrieve data, including application records and sessions. Development, testing, and production must all use PostgreSQL.
- Modularity and Code Quality: The code should be modular, well-structured, and follow best practices for code quality.
- Planning and Documentation: You should provide a clear plan for your API, including the endpoints, request/response formats, and especially diagrams like ERD (Entity-Relationship Diagram)
